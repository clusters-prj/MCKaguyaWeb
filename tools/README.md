# ホームページ編集ツール

PHPで動作するローカル向けの編集画面です。コードを書かずに、トップページの見出し・紹介文、ヒーロー画像、再現建築ギャラリー、お知らせを更新できます。

## 起動方法

プロジェクトのルートフォルダーでPHP開発サーバーを起動します。

```bash
php -S 0.0.0.0:8000
```

ブラウザーで [http://localhost:8000/tools/editor.php](http://localhost:8000/tools/editor.php) を開きます。編集画面から公開ページを別タブでプレビューできます。

### スマートフォンから開く

サーバーPCとスマートフォンを同じネットワークに接続し、`localhost` の代わりにサーバーPCのローカルIPアドレスを指定します。

```text
http://192.168.1.20:8000/tools/editor.php
```

上記のIPアドレスは例です。Windowsでは `ipconfig` を実行し、Wi-FiまたはEthernetの「IPv4 アドレス」を確認してください。ファイアウォールがPHP開発サーバーへの接続を確認した場合は、プライベートネットワークからのアクセスを許可します。

## 編集できる内容

- トップページの大見出し、紹介文、ヒーロー画像、画像の説明文
- 再現建築ギャラリー3テーマのタイトルと説明
- 各テーマでランダム表示する画像（複数選択可）
- トップページ下部のお知らせ3件
- ギャラリーで使用する画像のアップロード（WebP、PNG、JPEG、AVIF、15MB以下）

ギャラリーは「路上ライブが行われた道」「ネオン商店街」「川床」の順で表示されます。選択したテーマ内の画像から、ページを開くたびに1枚をランダムに選びます。

## 保存先

「変更を保存」すると `data/homepage.json` に書き込まれ、サイトへすぐ反映されます。アップロードした画像は `assets/gallery/` に保存されます。JSONファイルを削除または空にすると、サイトは初期設定の内容で表示します。

## アクセス範囲について

編集画面はローカルまたはプライベートネットワークからのみ開けます。このツールは公開サイトの管理画面ではありません。本番サーバーへ配置しないでください。編集ツールを使わないときは開発サーバーを終了してください。

## 画像の最適化（開発用）

`tools/optimize-images.mjs` は、画像を縮小して WebP に変換するスクリプトです。手元のPCで実行するだけの開発用ツールで、サイトの実行や本番サーバーには Node は不要です。

```bash
npm install                 # 初回のみ
npm run optimize            # ドライラン（変換後のサイズを表示するだけ）
npm run optimize -- --write # 実際に書き込む
```

既定の対象は `assets/howtoconnect` と `assets/gallery` です。オプション（`--delete-original` / `--max` / `--quality` / 対象ディレクトリ）はスクリプト冒頭のコメントを参照してください。拡張子が変わった画像は、ページ側の参照パスを手で直す必要があります。
