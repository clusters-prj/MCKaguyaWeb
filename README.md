# MCツクヨミ制作委員会 公式サイト

MCツクヨミ制作委員会の公式ウェブサイトです。Minecraft上に「超かぐや姫！」の舞台・ツクヨミを再現するプロジェクトや、コミュニティの活動を紹介します。

## 必要な環境

- PHP 8.0以降（ローカル確認にはPHP付属の開発サーバーを利用できます）
- Webブラウザー

## 主な構成

- `index.php` — トップページ
- `pages/` — 各案内ページ
- `templates/` — 共通ヘッダー、フッター、head
- `includes/` — ページ一覧と言語処理
- `lang/` — 多言語テキスト
- `assets/` — CSS、JavaScript、画像など
- `data/homepage.json` — ブラウザー編集ツールで保存したトップページの内容
- `tools/` — ローカル用ツール

サイト内の案内ページはPHPで構成しています。デプロイは手動です。ライセンスは設定しておらず、著作権は権利者に帰属します。
